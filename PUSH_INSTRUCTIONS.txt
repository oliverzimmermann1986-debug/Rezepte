RECIPE-FOCUS-VERSION PUSHEN
===========================

1. ZIP entpacken und Repository prüfen:

   cd Scrappercontainer-main-recipe-focus
   git status

2. Tests ausführen:

   python3 -m venv .venv
   .venv/bin/pip install -r requirements.txt -r requirements-dev.txt
   .venv/bin/pytest -q
   node --check app/static/app.js
   bash -n proxmox/install.sh

3. Änderungen committen:

   git add -A
   git commit -m "Make recipe search primary and remove file sync"
   git push origin main

4. Im Proxmox-LXC aktualisieren:

   cd /opt/scrapper
   sudo bash proxmox/install.sh

5. Danach prüfen:

   systemctl status scrapper-web scrapper-job.timer scrapper-db-backup.timer
   systemctl list-timers 'scrapper-*'
   journalctl -u scrapper-web -n 100 --no-pager

6. Oberfläche öffnen:

   /#recipes

Der Installer erstellt vor dem Update eine konsistente Datenbanksicherung und entfernt nicht mehr verwendete Alt-Units sowie den alten Konfigurationsblock.
