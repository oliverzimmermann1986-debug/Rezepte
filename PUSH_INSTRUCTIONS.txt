REZEPTE – ÜBERNAHME IN DAS RICHTIGE REPOSITORY

1. ZIP entpacken und vorhandenes Repository ersetzen/zusammenführen.
2. Änderungen prüfen:
   git status
   git diff --stat
3. Commit erstellen:
   git add .
   git commit -m "Rezepte: Butter-Yellow Mobile-First UI"
   git push

Update im bestehenden Container:
   cd /opt/scrapper
   git pull --ff-only origin main
   sudo bash proxmox/install.sh

Das Install-Script lädt bei bestehenden Installationen einen frischen Release-
Checkout und aktualisiert Code, venv, Browser und systemd-Units atomar mit
Rollback. Ein zusätzlicher manueller Dienst-Restart ist nicht nötig.

Browser danach einmal ohne Cache neu laden.
Das Initialpasswort wird bei Neuinstallationen vom Installer zufällig erzeugt
und in data/.initial-password abgelegt.
