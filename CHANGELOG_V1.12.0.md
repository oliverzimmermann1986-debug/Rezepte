# Rezeptregal Server 1.12.0

- Impressum, Datenschutz und Hilfe sind vor der Anmeldung und in den Einstellungen erreichbar. Tatsächliche Betreiberangaben werden lokal konfiguriert; unvollständige Angaben werden nicht veröffentlicht.
- KI-Funktionen in Web und iPhone verlangen eine ausdrückliche Freigabe pro Aktion. Abbrechen sendet keine Anfrage. Geteilte Links bleiben zunächst lokal; Übersetzungen starten bewusst.
- Der Server prüft die Freigabe vor der Verarbeitung. Wartende Aufträge behalten ihren freigegebenen Umfang; eine Freigabe für OpenAI erlaubt keine Übertragung an einen anders konfigurierten Anbieter.
- Das einzige Haushaltsmitglied kann Konto und privaten Haushalt ausdrücklich löschen. Eine unterbrochene Dateibereinigung wird wieder aufgenommen; weitere Mitglieder und fremde Haushalte werden geschützt.
- Datenbankschema 272 ergänzt die dauerhafte Löschvormerkung. Betreiberkonfiguration und bestandene Prüfungen sind vor der Veröffentlichung erforderlich.

Technische Verträge: `docs/LEGAL_CONFIGURATION.md`, `docs/AI_PROCESSING_CONSENT.md`, `docs/ACCOUNT_DELETION.md`.
