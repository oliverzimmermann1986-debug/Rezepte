              ( Findings)
            
            
          

        


        
        

          
          
          
          
        


        
        

          
        

          
📭 Verdächtig leer ()

          

            Rezepte mit Status „ok" aber 0 Zutaten — die KI hat in einem früheren Lauf nichts gefunden.
            Häufig PDF-Header / Markdown-Bullets die der alte Prompt übersehen hat.
            Klick „Alle neu extrahieren" setzt sie auf „pending", Worker probiert mit aktuellem Prompt.
          

          

            
          

          
        


        
        

          
🖼 Kein Bild ()
            
              
              
              
              
            
          

          

            Rezepte ohne Thumbnail. Reihenfolge nach Aufwand:
            🎬 Frame-Extract (schnellste, nutzt lokales Video) →
            🔄 Re-Scrape (frisch von TikTok/IG) →
            ✓ markieren (nicht reparierbar) →
            🗑 löschen (Rezept + Files weg).
          

          
        


        
        

          
📋 Keine Schritte () 

          

            Rezepte mit Zutaten aber leerer Schritt-Liste. KI hat keine fand oder Description war nur eine Zutatenliste.
          

          
        


        
        

          
🔗 Keine URL () 

          

            Rezepte ohne TikTok/Insta-URL. Meist manuell angelegt — kein Re-Scrape möglich.
          

          
        


        
        

          
🥄 Nur 1-2 Zutaten () 

          

            Rezepte mit nur 1-2 Zutaten. Möglich, aber meist Halbextrakt der KI — manuell editieren oder neu extrahieren.
          

          
        


        
        

          
📝 Keine Beschreibung () 

          

            Rezepte ohne (oder mit fast leerer) Beschreibung. KI kann nichts extrahieren — info.json oder .txt-Datei fehlt.
          

          
        


        
        

          
☐ Nicht verifiziert ()
            
          

          

            Rezepte mit ≥ 1 Zutat, die noch nicht manuell als ok markiert wurden.
            Klick „Ansehen" → im Modal ✓-Button. Oder pro Eintrag das ✓-Icon
            für schnelle Einzel-Verifikation. Bulk-Button setzt alle auf
            einmal (Vorsicht: pauschal).
          

          
        


        
        

          
📂 FS-Pfad fehlt ()
            
              
              
            
          

          

            DB-Pfad zeigt auf Folder der nicht (mehr) existiert. Auto-Heal
            sucht passenden FS-Folder (Underscore↔Space, Case). Bei
            'Kein FS-Match' ist der Folder weg — entweder im FS anlegen
            oder den DB-Eintrag löschen (🗑-Button am Eintrag oder Bulk).
          

          
        


        
        

          
⚡ Nährwerte fehlen ()
            
              
              
            
          

          

            Rezepte mit ≥ 3 Zutaten ohne KI-geschätzte Nährwerte. Bulk-Berechnung
            macht max. 50 in einem Lauf (~$0.025, ~30s) — bei mehr wiederholt klicken.
          

          
        

        

        

        
        

        
        

          
🔴 FS-Sync-Konflikte ()

          

            Diese Folder konnten beim letzten Sync nicht in die DB. Meist URL-Dubletten —
            ein anderer Folder hat schon die gleiche TikTok/Insta-URL.
            Klick „🔍 Vergleichen" um beide Folder Side-by-Side zu sehen und zu entscheiden welcher behalten wird.
